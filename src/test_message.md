# Как отправить тестовый донат с произвольным текстом

Для тестирования скрипта-слушателя донатов (`donationalerts_listener.py`) часто требуется проверить его реакцию на сообщения с разным текстом, суммами или именами отправителей. Стандартная кнопка "Сделать тестовое оповещение" обычно отправляет фиксированные данные. Отправлять реальные минимальные донаты может быть неудобно.

Есть более удобный способ отправить кастомное тестовое сообщение, которое будет перехвачено скриптом:

1.  **Войдите** в свой аккаунт DonationAlerts.
2.  Перейдите в раздел **"Последние сообщения"** (в левом меню).
3.  Нажмите кнопку **"Добавить сообщение"** (обычно находится вверху справа).
4.  **Заполните форму:**
    *   **Имя пользователя:** Введите любое имя.
    *   **Сумма:** Укажите любую сумму.
    *   **Валюта:** Выберите валюту.
    *   **Сообщение:** **Напишите тот текст, который вы хотите протестировать.**
5.  **Обязательно поставьте галочку** напротив **"Отобразить сообщение в виджете"**. Именно эта опция заставит DonationAlerts отправить событие через WebSocket, которое слушает наш скрипт.
6.  Нажмите кнопку **"Добавить"**.

После этого ваш скрипт `donationalerts_listener.py` должен получить событие `donation` с указанными вами данными и записать их в лог и файл `donations.log`.
