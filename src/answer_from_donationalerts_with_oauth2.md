# Формат Сообщения о Донате (Centrifugo WebSocket + OAuth)

После успешной аутентификации WebSocket-соединения и подписки на канал `$alerts:donation_<user_id>`, сервер DonationAlerts будет присылать уведомления о новых донатах. Эти сообщения приходят через WebSocket **без поля `id`** и имеют следующую общую структуру:

```json
{
  "result": {
    "channel": "$alerts:donation_<user_id>",
    "data": {
      "seq": <число>,
      "data": {
        // Объект с деталями самого доната
      }
    }
  }
}
```

**Разбор структуры:**

*   **`result`**: Корневой объект для push-сообщений в этом потоке.
    *   **`channel`**: Строка, указывающая на канал, из которого пришло сообщение (например, `"$alerts:donation_13907608"`). Наш код проверяет, что он начинается с `$alerts:donation_`.
    *   **`data`**: Внешний объект данных от Centrifugo.
        *   **`seq`**: Порядковый номер сообщения в канале (число). Может использоваться для восстановления пропущенных сообщений, если включена опция `recoverable` при подписке.
        *   **`data`**: **Самый важный объект, содержащий фактические данные о донате.**

**Поля объекта Доната (`result.data.data`):**

Этот вложенный объект содержит информацию, которую мы парсим и используем. Вот ключевые поля, наблюдавшиеся в логах:

*   **`id`**: Уникальный числовой идентификатор доната (например, `164405432`). **Важно** для дедупликации, если она потребуется.
*   **`name`**: Имя, указанное отправителем *при донате* (например, `"Donations"`). Используется как запасной вариант, если `username` отсутствует.
*   **`username`**: Имя пользователя DonationAlerts, если отправитель был авторизован. Может быть `null`, если донат анонимный или от незарегистрированного пользователя. **Наш код использует `username` или `name`.**
*   **`message`**: Текст сообщения доната (строка, например, `"\"Повесть о Конце Света\"\r\n"`). Может содержать управляющие символы вроде `\r\n`.
*   **`message_type`**: Тип сообщения (например, `"text"`).
*   **`payin_system`**: Платежная система (может быть `null`).
*   **`amount`**: Сумма доната (число, например, `22`).
*   **`currency`**: Валюта доната (строка, например, `"USD"`).
*   **`is_shown`**: Флаг, отображался ли донат в стандартных виджетах (число, `1` если да).
*   **`amount_in_user_currency`**: Сумма в валюте получателя (число).
*   **`recipient_name`**: Имя получателя (строка, например, `"jogaboga86"`).
*   **`recipient`**: Объект с информацией о получателе.
    *   `user_id`: ID пользователя DonationAlerts (число).
    *   `code`: Логин пользователя (строка).
    *   `name`: Отображаемое имя пользователя (строка).
    *   `avatar`: URL аватара (строка).
*   **`created_at`**: Время создания доната на сервере DA в формате `YYYY-MM-DD HH:MM:SS` (строка, например, `"2025-04-12 07:15:49"`).
*   **`shown_at`**: Время показа в виджете (может быть `null`).
*   **`reason`**: Причина события (например, `"default"`).

**Пример полного RAW сообщения из логов:**

```json
{"result":{"channel":"$alerts:donation_13907608","data":{"seq":15,"data":{"id":164405432,"name":"Donations","username":null,"message":"\"\u041f\u043e\u0432\u0435\u0441\u0442\u044c \u043e \u041a\u043e\u043d\u0446\u0435 \u0421\u0432\u0435\u0442\u0430\"\r\n","message_type":"text","payin_system":null,"amount":22,"currency":"USD","is_shown":1,"amount_in_user_currency":22,"recipient_name":"jogaboga86","recipient":{"user_id":13907608,"code":"jogaboga86","name":"jogaboga86","avatar":"https:\/\/static-cdn.jtvnw.net\/user-default-pictures-uv\/998f01ae-def8-11e9-b95c-784f43822e80-profile_image-300x300.png"},"created_at":"2025-04-12 07:15:49","shown_at":null,"reason":"default"}}}}
```

**Важно:** Формат может незначительно меняться или содержать дополнительные поля в зависимости от типа доната или обновлений API DonationAlerts. Логика парсинга должна быть достаточно гибкой (например, использовать `.get()` с значениями по умолчанию), чтобы обрабатывать возможные отсутствующие поля.
